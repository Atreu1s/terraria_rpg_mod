# Предложения для RPGMod 3.0

Главная задача версии 3.0 — сделать прогрессию после Лунного лорда интереснее в обоих режимах. Для следующего релиза достаточно одной новой ступени развития на класс и инструментов, которые помогут игроку понять работу билда.

| Приоритет | Что добавить | Первый результат |
| --- | --- | --- |
| 1 | **Испытания мастерства.** Отдельный путь после Лунного лорда для ванильной игры и продолжение через боссов Calamity | По два взаимоисключающих пассивных узла на класс. Ванильные испытания опираются на существующие события, а ветка Calamity открывается с учётом привычной прогрессии боссов |
| 2 | **Понятная обратная связь в бою.** Показывать, как работает выбранная специализация | Счётчики попаданий до пробуждения, стаки Жонглёра и перезарядка Уклонения. Показ можно отключить в клиентском конфиге |
| 3 | **Баланс по этапам игры.** Проверить, когда персонаж реально достигает уровней 25, 50 и 75 | Контрольные прохождения с Calamity и без него. Сравнить темп XP, урон по боссам и доступность тиров в одиночной игре и кооперативе |
| 4 | **Настоящий стелс Calamity.** Проверить, можно ли привязать отдельный навык к stealth strike через поддерживаемый API | Прототип одного узла с сохранением текущей «Тени» как отдельной механики |

Для первого играбельного этапа 3.0 достаточно испытания Воина в ванильном режиме, испытания Разбойника в Calamity и индикаторов обоих билдов. По результатам этих прохождений можно расширить механику на остальные классы.
