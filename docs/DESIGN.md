# RPG-мод для tModLoader + Calamity — дизайн-документ

Версия от 18.11.2026. Единственный источник правды по механикам. Все числа стартовые и выносятся в конфиг.

## 1. Обзор

RPG-прогрессия для Terraria + Calamity: уровни за убийства, 6 статов с ручным распределением, 4 класса и древо пассивных бонусов 4 → 8 → 16 → 32, открывающееся по уровню и победе над боссом. В первую очередь мод для одиночной игры, но мультиплеер заложен с самого начала.

| Параметр | Решение |
| --- | --- |
| Классы | 4: Воин, Стрелок, Маг, Призыватель. Разбойник (Rogue) не поддерживается, получает только общие бонусы (Выносливость, Удача) |
| Структура древа | 4 → 8 → 16 → 32: класс → тир 1 → тир 2 → тир 3, всего 60 узлов |
| Выбор класса | С 10-го уровня, в любой момент. Определяет классовый прирост статов |
| Тир 1 | 25 уровень + убита Стена плоти |
| Тир 2 | 50 уровень + убиты все три механических босса |
| Тир 3 | 75 уровень + убит Лунный лорд |
| Без класса | Тиры закрыты, пока класс не выбран |
| Максимальный уровень | Нет. После 75 — только очки статов |
| Статы | 6: Сила, Ловкость, Интеллект, Дух, Выносливость, Удача. Убывающая отдача внутри стата, без жёсткого потолка |
| Очки статов | +1 свободное за уровень + автоматический классовый прирост |
| Опыт | По «силе» монстра (HP, урон, защита) со штрафом за слабых мобов. Боссы — по таблице |
| Активные способности | Нет, только пассивные и условные бонусы |
| Респек | 2 предмета: «Сброс статов» и «Сброс древа». Сброс древа снимает пробуждение и возвращает Камень пробуждения |
| Масштабирование боссов | Нет. Сложность регулирует сам Calamity |
| Мультиплеер | Заложен сразу: опыт считает сервер, данные хранит игрок |
| Пробуждение | Одно на класс. Камень пробуждения из 3 эссенций боссов + материалов Providence и Стражей; доступно до Devourer of Gods |
| Стиль UI | Вариант A «ванильный инвентарь» — см. UI_SPEC.md |

## 2. Уровни, опыт и открытие тиров

Тир открывается, только когда выполнены оба условия: уровень и босс.

| Выбор | Уровень | Босс | Проверка в коде |
| --- | --- | --- | --- |
| Класс | 10 | — | — |
| Тир 1 | 25 | Стена плоти | `Main.hardMode` |
| Тир 2 | 50 | Все три механика | `NPC.downedMechBoss1 && NPC.downedMechBoss2 && NPC.downedMechBoss3` |
| Тир 3 | 75 | Лунный лорд | `NPC.downedMoonlord` |

**Правила выбора**

- Окно персонажа открывается кнопкой «Статус» в инвентаре. Без класса тиры закрыты; древо видно всегда, закрытые узлы показывают условие.
- Очки древа = число открытых тиров − число выбранных узлов тиров. Тратятся строго по цепочке: класс → тир 1 → тир 2 → тир 3. На каждом тире выбирается один из двух дочерних узлов, соседняя ветка закрывается.
- Поздний выбор класса не наказывается: классовый прирост статов вычисляется от текущего уровня, все открытые тиры выбираются подряд.

**Сила и уровень монстра** (подход как в ExperienceAndClasses)

- Сила считается по базовым характеристикам из `ContentSamples.NpcsByNetId`, чтобы режим сложности не менял уровень моба:
  `power = 0.6 * sqrt(lifeMax) + 0.8 * damage + 0.5 * defense`.
- Уровень монстра = power / 3 (зелёный слизень ≈ 2, зомби ≈ 6, бронированный скелет ≈ 26). Делитель калибруется в игре.
- Опыт за моба = 2 × power^1.5 × множитель разницы уровней × множитель событий × множитель из конфига. Во время нашествий и событий (Тыквенная и Ледяная луна, затмение, вторжения) множитель событий 0.5.
- Разница уровней (игрок − монстр): до 5 — 100%; дальше −10% за уровень, минимум 10%. За монстра сильнее игрока +5% за уровень, максимум +50%.
- Боссы: уровень из таблицы ниже, опыт = половина `xpToNext` уровня босса. Боссы неизвестных модов — по общей формуле × 5. Мини-боссы событий — по общей формуле.
- Не дают опыта: статуи (`SpawnedFromStatue`), городские NPC, дружественные и мелкие существа. У червей опыт даёт только главный сегмент (`realLife`).

**Опыт до следующего уровня:** `xpToNext(L) = 60 * L^2.5`, без потолка. Цель: 25 к Стене плоти, 50 к механикам, 75 к Лунному лорду; события не должны давать перепрыгнуть этапы. Темп намеренно медленный (выбор автора); множитель кривой — в конфиге. Опыт хранить в `long`.

| Отрезок | Нужно опыта | Типичный моб | Убийств (без боссов и событий) |
| --- | --- | --- | --- |
| 1 → 25 | 1,25 млн | ~250 | ~5000 |
| 25 → 50 | 13,4 млн | ~1700 | ~7800 |
| 50 → 75 | 46,6 млн | ~3700 | ~12 700 |
| 75 → 100 | 107 млн | ~10 400 | ~10 300 |

## 3. Статы

У каждого из 5 классовых статов есть основной эффект (урон своего класса) и вторичный, полезный всем. Удача — общий стат.

| Стат | Основной эффект | Вторичный эффект |
| --- | --- | --- |
| Сила | Урон ближнего боя, до +60% | Скорость атаки ближнего боя, до +20% |
| Ловкость | Урон дальнего боя, до +60% | Скорость передвижения, до +25%; шанс не потратить патрон, до 25% |
| Интеллект | Урон магии, до +60% | +1 мана за очко, до +200; расход маны, до −25% |
| Дух | Урон миньонов, до +60% | +1 слот миньона на 30, 80 и 150 очках; скорость и дальность хлыстов, до +30% |
| Выносливость | Макс. HP, до +200 | Снижение урона, до 15%; +1 регенерации за каждые 25 очков |
| Удача (общий) | Шанс крита всех классов, включая Разбойника, до +15% | `Player.luck`, до +0,3 |

**Убывающая отдача:** `bonus(n) = X * n / (n + 100)`, где X — значение «до». Линейные исключения: мана за Интеллект, слоты за Дух, регенерация за Выносливость. Для урона (X = 60%): 25 очков → 12%, 50 → 20%, 100 → 30%, 200 → 40%, 500 → 50%.

**Классовый прирост** (за уровень, сумма у всех 0,85). Не хранится, а вычисляется: `floor(уровень × коэффициент)`.

| Класс | Сила | Ловкость | Интеллект | Дух | Выносливость |
| --- | --- | --- | --- | --- | --- |
| Воин | 0,5 | — | — | — | 0,35 |
| Стрелок | — | 0,6 | — | — | 0,25 |
| Маг | — | — | 0,6 | 0,1 | 0,15 |
| Призыватель | — | — | 0,1 | 0,55 | 0,2 |

Пример: Воин 75 уровня, все свободные очки в Силу: 37 + 75 = 112 очков ≈ +32% урона ближнего боя.

**Респек.** «Сброс статов» возвращает все свободные очки. «Сброс древа» сбрасывает класс, все узлы и пробуждение (Камень пробуждения возвращается в инвентарь); очки древа пересчитываются. Рецепты на верстаке: «Сброс статов» = 1 дерево (Wood) + 1 упавшая звезда (Fallen Star), «Сброс древа» = 1 дерево + 2 упавшие звезды.

## 5. Пробуждение

Одно пробуждение на класс. Собирается до Devourer of Gods, поэтому работает на DoG, Yharon, Exo Mechs и Supreme Calamitas.

1. **Подсказка.** После Лунного лорда под выбранным узлом тира 3 появляется слот «???» с намёком: «Сила спит в сердцах тех, кто пал после Луны».
2. **Эссенции.** Providence, Ceaseless Void, Storm Weaver, Signus и Polterghast роняют «Эссенцию пробуждения» за сам факт убийства. Нужно 3 эссенции с разных боссов. В мультиплеере дроп личный для каждого игрока.
3. **Крафт.** Первая эссенция открывает рецепт в подсказке. Камень пробуждения = 3 Эссенции пробуждения + 10 Divine Geode (Providence) + 3 Armored Shell (Storm Weaver) + 3 Dark Plasma (Ceaseless Void) + 3 Twisting Nether (Signus), на Древнем манипуляторе. Стражей можно призвать сразу после Лунного лорда.
4. **Использование.** Требует выбранный узел тира 3. Вспышка, звук, сообщение в чат.

**Сброс.** «Сброс древа» снимает пробуждение и возвращает Камень. Камень не привязан к классу.

| Класс | Пробуждение | Основной эффект | Надбавка от подкласса тира 1 |

**Мультиплеер**

1. `OnKill` выполняется на сервере (или в одиночной игре). Сервер считает опыт.
2. Опыт получает каждый игрок с `npc.playerInteraction[i] == true`; сервер отправляет ему `ModPacket` «+N XP».
3. Клиент начисляет опыт и повышает уровень у себя; данные сохраняются в персонаже через `SaveData` / `LoadData`.
4. Изменения рассылаются через `SyncPlayer`, `CopyClientState`, `SendClientChanges`.
5. В одиночной игре тот же код без пакетов.

**Ключевой код**

```csharp
public record SkillNode(string Id, string ParentId, int Tier, Action<Player> Apply);

// RPGPlayer
public int Level, ClassId;
public long XP;
public int[] Invested = new int[6];
public HashSet<string> Picked = new();
public bool Awakened;

public int GetStat(Stat s) => Invested[(int)s] + (int)(Level * ClassGrowth.Get(ClassId, s));

public int TiersUnlocked() =>
    (Level >= 25 && Main.hardMode ? 1 : 0)
  + (Level >= 50 && NPC.downedMechBoss1 && NPC.downedMechBoss2 && NPC.downedMechBoss3 ? 1 : 0)
  + (Level >= 75 && NPC.downedMoonlord ? 1 : 0);

public int TreePoints() => ClassId == 0 ? 0 : TiersUnlocked() - (Picked.Count - 1); // -1: сам класс

public override void PostUpdateEquips()
{
    Player.GetDamage(DamageClass.Melee) += StatMath.Soft(GetStat(Stat.Str), 0.60f);
    // ... остальные статы
    foreach (var id in Picked)
        if (SkillTree.Nodes.TryGetValue(id, out var node)) node.Apply(Player);
}
```

Условные эффекты (стаки, «стоя на месте», перезарядки) живут в полях `RPGPlayer` и хуках `ModifyHitNPC`, `OnHitNPC`, `ModifyHurt`, `PreKill`.

## 7. Порядок разработки

1. Скелет: `RPGPlayer`, опыт по силе монстра, полоса XP. Сразу с пакетами мультиплеера.
2. Статы: 6 статов, панель с кнопками «+», формулы из `StatMath`.
3. Классы и тир 1: выбор класса, классовый прирост, 8 подклассов. Древо пока списком кнопок.
4. Тиры 2 и 3: условные эффекты, проверка боссов.
5. Респек-предметы.
6. UI по UI_SPEC.md (вариант A) с иконками из Codex.
7. Пробуждение: эссенции, Камень, эффекты.
8. Баланс: тестовое прохождение и подстройка чисел в конфиге.
